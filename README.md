## 📖 Description
The **NLP Maternal Health Dataset** contains multilingual maternal health data designed to support the development of **NLP-powered chatbots**.  
It provides structured weekly advice and information for expectant mothers, including:  

- **baby_development**: length, weight, summary  
- **maternal_changes**: physical and psychological adaptations  
- **body_changes**: physiological developments  
- **tips**: practical advice for expectant mothers  
- **plan**: guidance for preparation and care  

Languages covered include **English, Shona, Ndebele, Nyanja, Tonga, Bemba, and Lozi**.  
The dataset is intended for research, innovation, and deployment of maternal health solutions in digital health platforms.
